# Prompt log

Every instruction Maurici gives about this project is stored here word for word,
in the order it arrived. Nothing is paraphrased, corrected or tidied up. Typos stay.

Why keep them: the issues and the code are an interpretation of these words. When an
agent has to decide what "free time" or "waiting time" means, the answer is in here,
not in someone's summary of it.

## Convention

- One file per prompt, numbered in order: `001-…`, `002-…`.
- The verbatim text lives inside a fenced block so no Markdown renderer eats it.
- Anything the agent inferred goes under "Derived decisions", clearly separated from
  the user's own words.
- Issues that come from a prompt quote the exact lines they implement and link back here.
