# Screenshots

Evidence for pull requests that change how something looks.

AGENTS.md requires an agent redesigning a screen to capture its own work and judge it from
the image. A screenshot sitting in a scratch directory proves nothing to a reviewer, and
there is no API for attaching an image to a pull request, so committing it here is the only
way to put it in front of one.

Name a file for what it shows and at what size, for example
`result-card-mobile-390-dark.png`. Reference it from the PR body with a raw GitHub URL so it
renders inline.

Keep them small, and delete a screenshot once the thing it documents has changed. These are
review artefacts with a short life, not a design archive.
